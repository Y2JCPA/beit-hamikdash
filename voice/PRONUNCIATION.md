# Pronunciation guide for the English recordings

The English lines are full of Hebrew words. They must sound like **modern Israeli Hebrew**, not like English spelling.

## The rules
- **"ch" in a Hebrew word is the throaty sound in "Bach" or "loch"** (IPA /χ/), never the "ch" in "chair".
  Chodesh = **KHO-desh**, Pinchas = **peen-KHAHS**, Mizbeach = **meez-BEH-akh**, baruch = **bah-ROOKH**.
  English words keep their English "ch": chamber, children, chest, each, which, much.
- Vowels are always pure: a = "ah", e = "eh", i = "ee", o = "oh", u = "oo".
- An apostrophe or a short ' (as in HaTla'im) is a tiny break, not a silent letter.
- "Ha" at the start of a word means "the" and is said "hah", joined to the word: HaMikdash = **hah-meek-DAHSH**.
- In the table, CAPITALS mark the stressed syllable and "kh" is the throaty sound.

## How to use this guide
The recording must say each line's text, but the text-to-speech input can be adjusted so it pronounces it right.
- If the voice supports a pronunciation dictionary, aliases or phoneme/IPA tags, add these words there. Use /χ/ for "kh".
- Otherwise, swap the respelling below into the input text when generating that line.
- **Never change the file name:** it is always the line's `id` from `lines.json`.
- Listen to a few lines with "ch" words and check them before recording everything.

The Hebrew recordings use a native Hebrew voice. If it misreads a word written without vowels, you may add nikud (vowel points) to the text-to-speech input only.
